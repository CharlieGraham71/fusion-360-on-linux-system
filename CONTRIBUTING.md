# Contributing

Thanks for helping! This project is about getting **Autodesk Fusion** running well on Linux,
so real-world test results are the most valuable thing you can share.

## Most useful contributions

1. **Test reports** – did it work on your distro / desktop / graphics card / Wine version?
   Open an issue using the **Test report** template (works *and* doesn't-work reports both help).
2. **Help with the open `needs-testing` issues** – see the Issues tab. Comment with what you tried
   and what happened.
3. **Fixes to the scripts or docs** – via a pull request (below).
4. **New ScriptBridge examples** – small Fusion scripts that do something useful.

## Asking questions

Use the **Discussions** tab for questions and ideas ("does this work on Ubuntu?"),
and **Issues** for bugs and test results.

## Sending a pull request

1. Click **Fork** (top right) to make your own copy.
2. Make your change in your fork (you can edit files right on GitHub).
3. Click **Contribute → Open pull request**.
4. In the description say **what** you changed, **why**, and **what you tested it on**
   (distro, desktop, GPU, Wine version, Fusion version).

Please keep changes small and focused – one fix per pull request is easiest to review.

## Ground rules

- Don't upload Autodesk Fusion itself, installers, licence keys or account details.
- Never post tokens, passwords or personal info in issues or logs – check logs before pasting.
- Be kind; everyone here is volunteering their time.

By contributing you agree your contribution is released under this repo's [MIT licence](LICENSE).
